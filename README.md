# Мастерская снаряжения — конструктор кастомной формы (Arma 3)

Раздел сайта, где игроки собирают кастомную сборку оружия или комплект
экипировки, крутят модель в 3D и отправляют заказ. Фиксированная цена за
раздел: **оружие — 500 ₽**, **экипировка — 1000 ₽** (цена не зависит от
выбранных опций внутри раздела).

Стек: React 19 + TypeScript + Vite, `@react-three/fiber` / `@react-three/drei`
(Three.js) для 3D-вьювера, Zustand для состояния сборки, Tailwind CSS для
интерфейса в тёмной жёлто-чёрной теме.

## Быстрый старт

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # прод-сборка в dist/
npm run lint      # oxlint
```

## Структура

```
src/
  data/catalog.ts        — каталог оружия/экипировки (категории, опции)
  store/useBuilderStore.ts — состояние текущей сборки (Zustand)
  components/
    Header.tsx            — шапка с переключателем "Оружие / Экипировка"
    WeaponBuilder.tsx      — экран сборки оружия
    EquipmentBuilder.tsx   — экран сборки экипировки (форма на персонаже)
    ModelStage.tsx         — 3D-сцена: камера, свет, OrbitControls, авто-фолбэк
    GLTFModel.tsx           — загрузка настоящей GLB/GLTF модели
    WeaponPlaceholder.tsx   — процедурная заглушка оружия (пока нет арта)
    MannequinPlaceholder.tsx — процедурная заглушка персонажа
    OrderModal.tsx          — форма оформления заказа
  lib/orderSummary.ts     — превращает выбор в читаемый текст для формы/бэкенда
api/
  order.js                — серверная функция: шлёт заказ в Telegram-бота
```

## Как подключить настоящие 3D-модели

Пока у художника нет готового арта, каждая позиция в 3D рисуется
**процедурной заглушкой** (`WeaponPlaceholder` / `MannequinPlaceholder`) —
она крутится, реагирует на выбранные опции и никогда не ломает страницу.

Когда появится готовая модель (`.glb`):

1. Положите файл в `public/models/...` (например
   `public/models/weapons/ak74.glb`).
2. Пропишите путь в `src/data/catalog.ts` в поле `modelUrl` нужного оружия
   или опции экипировки.
3. Всё остальное подключится само: `ModelStage` увидит `modelUrl`, загрузит
   модель через `GLTFModel`, автоматически отцентрует и отмасштабирует. Если
   файл не найден или битый — страница не упадёт, а покажет прежнюю
   заглушку (`ModelErrorBoundary`).

Каждая позиция подключается независимо, поэтому можно постепенно заменять
заглушки на реальный арт, не трогая код.

## Оформление заказа и Telegram-уведомления

Кнопка «Оформить заказ» открывает форму (ник, Discord/Steam ID,
комментарий) и отправляет `POST` на `VITE_ORDER_API_URL` (по умолчанию
`/api/order`). Функция `api/order.js` — это Vercel serverless function:
она проверяет данные и пересылает заказ сообщением в Telegram через уже
существующего бота модерации, чтобы заказы приходили туда же, где админы
уже смотрят.

Нужны переменные окружения (задаются в панели хостинга, **не в коде**):

- `TELEGRAM_BOT_TOKEN` — токен бота из @BotFather
- `TELEGRAM_ADMIN_CHAT_ID` — id чата/группы, куда слать уведомления

См. `.env.example`.

> Если бэкенд ещё не поднят или переменные не заданы — форма покажет
> понятную ошибку «Не удалось отправить заказ», а не сломает страницу.

## Интеграция в основной сайт

Этот репозиторий — самостоятельный фронтенд-модуль. Варианты встраивания
в основной сайт сервера (когда он появится):

- Скопировать `src/` как отдельный роут/страницу в основной проект (если
  он тоже на React/Vite).
- Собрать (`npm run build`) и встроить `dist/` как статический раздел
  (например, по пути `/customizer`) или через `<iframe>`.
- Использовать `api/order.js` как есть — это самостоятельная serverless-
  функция, ей не важно, кто её вызывает.

## Настройка темы/названия сервера

Через `.env`:

```
VITE_SERVER_NAME="Название вашего сервера"
```

## Примечание по безопасности

В `api/order.js` токен бота и id чата читаются только из переменных
окружения — никогда не хардкодьте токен в коде и не коммитьте `.env`
(см. существующий `bot.py` в репозитории `tg-moderator`, где токен
сейчас лежит прямо в исходниках — токен уже скомпрометирован и стоит его
отозвать/перевыпустить у @BotFather, а новый брать только из переменных
окружения).

# Конвертация моделей Arma 3 → .glb (пакетно)

Все шаги — на Windows (Arma 3 Tools и Object Builder — Windows-only), но
если модели уже лежат распакованными (`.p3d`/`.paa`) — можно начать сразу
с шага 3 на любой машине с Blender.

## Инструменты (один раз установить)

1. **Blender** (актуальная версия, бесплатно) — https://www.blender.org
2. **Аддон «Arma 3 Object Builder»** для Blender —
   https://github.com/MrClock8163/Arma3ObjectBuilder (есть и в каталоге
   официальных расширений Blender). Это современный, активно
   поддерживаемый аддон для импорта/экспорта `.p3d` — умеет **пакетный**
   импорт из коробки.
3. **Mikero's Tools** (`extractpbo` и др.) — для распаковки `.pbo`-архивов
   Arma 3 (в игре или в моде) на отдельные файлы. Ищется по названию
   «Mikero DePbo Tools».
4. **P3D Debinarizer** — переводит «скомпилированные» игровые `.p3d` в
   текстовый MLOD-формат, который понимает Blender-аддон. Идёт в составе
   Arma 3 Tools (Steam → инструменты) либо отдельно от Mikero.
5. Конвертер текстур `.paa` → `.png` — можно онлайн
   (paa.gruppe-adler.de) или через сам аддон Arma 3 Object Builder, у
   него есть встроенный импорт `.paa`.

## Откуда брать исходники

- Из папки установленной Arma 3 (ванильное оружие/экипировка) — но это
  ассеты Bohemia Interactive, аккуратно с распространением вне игры
  (см. EULA).
- Из конкретного мода — только с разрешения автора мода.
- Собственная модель с нуля — этот блок вам вообще не нужен, сразу
  экспортируйте из Blender в `.glb`.

## Шаги

1. **Распаковать `.pbo`** нужных аддонов инструментом Mikero
   (`extractpbo`) — на выходе россыпь `.p3d` и `.paa` в папке.
2. **Дебинаризовать все `.p3d` разом** — P3D Debinarizer тоже умеет
   скормить ему целую папку и обработать всё за один прогон. На выходе —
   файлы вида `имя_mlod.p3d`.
3. **Импортировать всё разом в Blender**: Text Editor → Templates →
   Object Builder → шаблон **«P3D batch importer»** (идёт в комплекте
   аддона) → указать папку с `_mlod.p3d` → запустить. Каждая модель
   попадёт в сцену отдельной коллекцией — руками таскать файлы один за
   другим не нужно.
4. **Почистить каждую модель**: оставить только нужный Visual LOD
   (обычно LOD0), скрыть/удалить коллекции Shadow, Geometry, Point cloud,
   ViewPilot/ViewGunner и т.п. Применить текстуры (шаг с `.paa` → `.png`)
   в Shading-вкладке.
5. **Экспортировать всё разом в `.glb`** — скрипт
   [`blender_batch_export_glb.py`](./blender_batch_export_glb.py) из этой
   папки проходит по всем коллекциям в сцене и сохраняет каждую в свой
   `.glb`-файл за один запуск. Откройте его в Scripting-вкладке Blender,
   поправьте `OUTPUT_DIR` и запустите (или через
   `blender ... --background --python blender_batch_export_glb.py`).
6. **Загрузить `.glb`-файлы через `/admin`** на сайте — по одному на
   каждую единицу оружия/экипировки, как описано в главном `README.md`.

Если модели крупные/тяжёлые — можно уменьшить размер через Blender's
Decimate-модификатор перед экспортом, либо сжать текстуры до 1–2K перед
запеканием в материалы.
